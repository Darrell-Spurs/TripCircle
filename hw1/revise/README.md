# Darrell's Personal Page

A simple, self-contained personal page built with HTML, CSS, and TypeScript.

## How to open the webpage? 
 Simply open `index.html` in your browser.

## Features

- **Three Main Sections**: Home, About, and Related Sites
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with smooth animations
- **Self-Contained**: No build process or external dependencies needed

## File Structure

```
hw1/
├── index.html          # Home page
├── about.html          # About page with detailed information
├── related_sites.html  # Related sites and resources page
├── styles.css          # CSS styles for all pages
├── script.ts           # TypeScript source code
└── README.md           # This file
```

## Features Overview

### Navigation
- Click on navigation links to visit different pages
- Home page with overview and quick access
- About page with detailed personal and professional information
- Related Sites page with social media links and resources
- Scroll down to the footer for more ways of contact and social media links

### Responsive Design
- Automatically adapts to different screen sizes
- Mobile-friendly navigation
- Optimized layouts for tablets and phones

## Customization

### Adding Content
Edit the HTML file to customize:
- Personal information in the About section
- Links in the Related Sites section
- Project descriptions in the Home section

## Technical Details

- **HTML5**: Semantic markup with accessibility features
- **CSS3**: Modern styling with flexbox and grid layouts
- **TypeScript**: ES2017+ features with type safety
- **No Dependencies**: Pure web technologies, no frameworks or libraries
