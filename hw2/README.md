# Brick Breaker

## 執行遊戲

### 執行方法
1. 在 `hw2` (或解壓縮後的資料夾) 中開啟 Terminal 
2. 執行以下其中一個指令：
   - **./start_server.sh** (Preferred)
   - **Python 3**: `python3 -m http.server 8000`
   - **Node.js**: `npx http-server -p 8000`
3. 開啟瀏覽器並前往 `http://localhost:8000`

## 遊戲內容
### 遊戲規則
- 由擊碎方塊來得分
- 清空遊戲版變上的方塊後，即會進入下一關
- 每回合開始時有 **3顆球**
- 球會從選擇的方向從球拍的同一位置連續發射
- 當三顆球皆落地，會扣一個生命值🩷
- 進入新的關卡後，會補滿三個生命值🩷🩷🩷
- 失去所有生命值，遊戲即會結束

### 操作方式
- 左右方向鍵（發射前）：改變發射方向
- 左右方向鍵 或 A/D鍵（遊戲中）：移動球拍
- 空白鍵：開始遊戲、發射球或暫停/繼續

#### 磚塊類型
-**普通磚塊** (淺藍色)：需 1 次擊中，10分
- **強力磚塊** (深藍色)：需 3 次擊中，30分
- **超強磚塊** (綠色)：需 5 次擊中，50分
- **移動磚塊** (淺藍色)：需 1 次擊中，水平移動，15分
- **移動強力磚塊** (藍色)：需 2 次擊中，水平移動，25分
- **固定磚塊** (灰色)：無法被破壞
- 磚塊受損時顏色會由紅 - 橘 - 黃 - 綠 - 藍的顏色改變，表示所擊碎所剩下的次數越少
