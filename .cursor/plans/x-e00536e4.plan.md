# Frontend API Integration Plan

1. api-client-setup

- Configure base URL handling (environment-based) and shared fetch helper with typed responses.  
- Add error handling utilities and request hooks.

2. data-hooks

- Implement React query hooks (or SWR) for timelines, profiles, posts, drafts, notifications.  
- Ensure optimistic updates for likes/reposts/drafts and character-limit validation reuse.

3. page-integration

- Wire Home timeline, Profile, Likes tabs, and Post composer to use new hooks/services.  
- Replace static data mocks and ensure navigation (post creation -> timeline refresh).

4. state-sync

- Remove sessionStorage hacks; rely on API responses for newly created posts/drafts.  
- Persist current user context and cache invalidation rules.

5. testing-pass

- Add integration tests for API hooks (mock server) or Cypress smoke tests covering major flows.  
- Verify loading/error states and SSR hydration match.
