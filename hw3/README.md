# HW3 商品目錄系統 
> 一個純前端的商品目錄與暫存容器系統，使用 React + TypeScript 建構，資料來源為 CSV 檔案。

## 安裝及執行

```bash
cd hw3
npm install
npm run dev
```

啟動後會：
1. 自動將 `src/public/data/*.csv` 同步到 `public/data/`
2. 監看 CSV 檔案變更並自動同步
3. 啟動 Vite 開發伺服器（預設 http://localhost:5173）

## 功能導覽
1. **瀏覽商品**（首頁 `/`）
   - 查看範例商品
   - 使用搜尋與篩選功能
   - 點擊「加入」將項目加入容器

2. **暫存容器**（`/container`）
   - 調整數量
   - 新增備註
   - 查看總覽

3. **送出記錄**（`/submit`）
   - 按下「送出記錄」按鈕
   - 完成三步驟流程
   - 自動導向歷史記錄

4. **查看記錄**（`/records`）
   - 檢視已送出的記錄
   - 匯出 JSON
   - 複製到容器進行修改

5. **修改 CSV 資料**
   - 開啟 `src/public/data/items.csv`
   - 修改內容後儲存
   - 開發伺服器會自動重新載入

## 功能特色

- **項目瀏覽**：搜尋、分類篩選、每頁顯示數量、價格與評分篩選、多種排序方式
- **暫存容器**：可新增、修改數量、備註、移除項目
- **送出記錄**：步驟化提交流程，記錄永久儲存
- **歷史記錄**：查看、匯出 JSON、複製為新容器
- **CSV 熱更新**：修改 CSV 檔案後自動同步與重新載入

## 技術棧

- **前端框架**：React 18 + TypeScript
- **建構工具**：Vite
- **UI 框架**：Material UI (MUI)
- **路由**：React Router v6
- **狀態管理**：React Context + 自訂 Hooks
- **CSV 解析**：Papa Parse
- **持久化儲存**：localStorage
- **測試**：Vitest
- **程式碼品質**：ESLint + Prettier

## 📊 CSV 資料格式

### 必要欄位（建議）

| 欄位名稱 | 說明 | 範例 |
|---------|------|------|
| `id` | 唯一識別碼（若無，系統自動產生） | `1` |
| `name` | 項目名稱 | `無線藍牙耳機 Pro` |
| `category` | 分類 | `電子產品` |
| `description` | 簡述 | `高品質降噪藍牙耳機` |
| `image_url` | 圖片 URL（使用雲端連結） | `https://images.unsplash.com/photo-...` |
| `price` | 價格（數值） | `3990` |
| `rating` | 評分（數值） | `4.5` |
| `stock` | 庫存（數值） | `50` |

### 動態欄位

除了上述欄位，您可以新增任何欄位，系統會自動顯示：

```csv
id,name,category,price,brand,warranty,color
1,產品A,類別1,1000,品牌X,2年,黑色
```

### 如何更新資料

1. **開發模式**：直接編輯 `src/public/data/items.csv`，儲存後會自動同步並重新載入
2. **新增 CSV**：將新檔案放到 `src/public/data/`，檔名需為 `*.csv`
3. **多檔案**：若需載入多個 CSV，請修改 `src/context/DataContext.tsx` 的 `csvUrls` 參數


## 🗺️ 頁面說明

### 1. 瀏覽商品（`/`）

- 搜尋框
- 分類多選篩選
- 價格區間、最低評分篩選滑桿
- 排序選擇（價格、評分、名稱、庫存）
- 分頁顯示（自訂每頁 5、10、20、50 個項目）
- 「加入容器」與「查看詳情」按鈕

### 2. 購物車（`/container`）

- 列出容器內所有項目
- 調整數量（+-）
- 新增備註
- 移除項目
- 顯示摘要（種類、總數、總金額）
- 「清空容器」與「送出記錄」按鈕

### 3. 送出記錄（`/submit`）

- 三步驟流程：
  1. 確認項目
  2. 最終檢查
  3. 完成送出
- 提交後清空容器並建立永久記錄
- 3 秒後自動導向記錄頁

### 4. 歷史記錄（`/records`）

- 表格列出所有記錄（最新在上）
- 可查看詳情（Dialog）
- 匯出單筆或全部記錄（JSON 格式）
- 複製記錄到容器（再次編輯）
- 刪除單筆或清除全部

## 💾 資料持久化

所有資料儲存在瀏覽器的 `localStorage`：

- **容器（暫存）**：`catalog_container`
- **已送出記錄**：`catalog_records`

清除瀏覽器資料會遺失所有記錄。匯出功能可備份 JSON 檔案。
