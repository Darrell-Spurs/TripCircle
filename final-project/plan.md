# Final Project – Midterm Plan

## Deploy Link

https://trip-circle.vercel.app/

## 1. 本次 Prototype 已完成

- 基本頁面架構（首頁 Feed、我的行程、行程詳情、分享頁面）
- 使用者認證系統（Email/密碼 + Google OAuth）
- 行程管理 CRUD（建立、編輯、刪除行程）
- 每日行程規劃（活動新增、編輯、刪除）
- 拖放排序活動功能
- 行程分享連結產生
- 公開 Feed 瀏覽已發布行程
- 行程發布與取消發布
- 行程匯入功能（從分享連結匯入為模板）

## 2. 最終版本預計完成項目

- 完整的使用者流程優化
- Feed 搜尋與篩選功能
- Feed 內容可點擊跳轉（地點、標籤等）
- 行程日期修改（含活動同步處理）
- 貼文收藏與留言功能
- 發布者數據儀表板（瀏覽數、匯入數、收藏數）

## 3. 預期開發進度

- Week 1: 完成 Feed 搜尋篩選 / Feed 內容點擊跳轉
- Week 2: 完成貼文收藏與留言功能 / 行程日期修改邏輯
- Week 3: 發布者儀表板 / 介面調整與最終整合
